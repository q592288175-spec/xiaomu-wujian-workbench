# 验收案例

以下均为人工构造情景，不是真实行情或业绩。用于读取规则后的行为验收；本文件列出预期，不代表自动完成验证。

|---|---|

| 保守、五层、周K | 最终比例0.5% |
| 积极、四层同向且第五层中性、周K | 最终比例0.5%，不加仓 |

| 净值高点100000，净权益95000 | 5%边界进入保守 |

| 收盘才能确认，回放用当根收盘成交 | 拒绝未来信息假成交，改用可执行时点核算 |
| 只有一个反K且无有效前一反K | 配对缺定义，不擅自换止损 |
| 未知保证金上限／没有账户高点历史 | 可以出条件卡，不能批准精确执行手数 |
| 止损触发但未收到成交确认 | 不记为已退出，进入人工异常处理 |

真实验收还需使用用户实际图例核对触发、持有和退出的唯一性。本包未完成收益回测或实盘验证。
