# 规则与计算口径 v1.0.0

状态：当前规则／效果验证中。依据：五简2026-09-27确认稿及“先按照这个生成决策技能包”的授权。

## 0. 顺势交易纲领（2026-10-02用户确认补充）

无论行情如何，都不能以任何理由做逆日K十均线或逆周K十均线方向的单子。可以不做、可以等节奏；要做就必须顺势。上涨只考虑顺势低多、突破多、穿十均线多；下跌只考虑顺势高空、突破空、穿十均线空。涨多、跌多、远离均线、预计回调或反弹，均不能作为逆势开仓理由。

日K与周K十均线沿用事前明确的判向口径；拟交易方向逆其中任一周期，拒绝新增风险。两者方向冲突或方向证据不清时等待，不换周期为逆势找理由。这是新增风险的前置约束，观察名单、五层数量、盘感和已有止损均不能豁免。

本条适用于新开仓、加仓、止损后再试及反手新增风险，不阻止止损、减仓和平仓。顺势突破仍须完整触发、有效止损、以损定量及账户许可，不放宽原有允许成交范围和信号过期限制。风险比例及其他参数不变；本次补充优先于旧文档的冲突表述。

## 1. 最小闭环和输入

五层择境 → 账户定攻守 → 周期定上限 → 结构定进退 → 以损定量 → 条件加仓 → 成交复核 → 退出归因。

需要的输入：品种中文名、具体合约、方向；五层状态及各层标的、规则版本、数据截止与失效时间；研究结论、反证、事件；各周期图形与完成状态；账户净权益、阶段本金、已平仓净利润、经资金进出调整的净值高点、当前档位、降档恢复高点、停机状态；已有仓位、入场价、最新可执行价格、止损、费用、相关风险单元；合约乘数、最小变动价位、手续费、滑点、保证金要求及流动性约束。

净权益包含浮动盈亏。阶段本金固定，资金进出按账户既定记账规则调整基准，不把入金记利润。缺高点历史不能推断回撤正常；缺状态历史不能擅自恢复。阶段本金和净值高点不是同一个概念。

用户于2026-09-28确认：默认阶段本金及仓位、风险预算、手数示例统一按1,000,000元（100万元）计算，不再按10万元举例。真实交易仍以本轮首次批准前核实的实际净权益E0冻结预算；实际净权益与100万元不一致时必须标明差额，不能把默认测算基准冒充实时账户事实。详见`02_日常/2026-09-28_账户计算基准_当前_v1.0.md`。

## 2. 五层权限

顺序：大盘 → 板块 → 品种月K → 品种周K → 品种日K。

方向使用上游明确的多头／空头／中性／未知。按拟交易方向统计同向层数。

| 状态 | 新增权限 | 环境风险上限 |
|---|---|---:|
| 少于四层同向 | 不新增 | 0 |
| 四层同向且第五层中性 | 观察及保守测试，仍需触发 | 0.5% |
| 四层同向且第五层明确反向 | 只观察，待冲突修复 | 0 |
| 任一层未知、证据失效或关键时间口径不一致 | 待补证据，不新增 | 0 |
| 五层同向 | 核心环境，允许评估正常／积极 | 2% |

明确不同向的层。小周期只是执行观察工具，不算第六层。研究观点不能更改五层事实。不要自行给大盘、板块创造指标判向规则。

## 3. 固定三档与周期上限

| 账户档位 | 单轮上限 | 组合风险池 |
|---|---:|---:|
| 保守 | 0.5% | 当前净权益的2.5% |
| 正常 | 1% | 当前净权益的5% |
| 积极 | 2% | 当前净权益的6% |

| 主周期 | 周期上限 |
|---|---:|
| 周K | 2% |
| 日K | 1% |
| 小周期／市场情绪型交易 | 0.5% |

最终比例=min(账户单轮上限,环境风险上限,周期上限)。不乘折扣，不生成0.125%、0.25%等新档。

主周期由持有与失效依据确定。周K背景、日K决定进退按日K；小周期仅用于执行优化不自动改主周期，必须事前明确。个人冲动不是“市场情绪型”机会。

账户冻结预算E0×最终比例，E0为本轮首次批准前核实的净权益。浮盈和环境升级不自动扩充本轮预算；降档后新增风险还要受当前较低额度限制。

## 4. 账户状态机

峰值回撤D=(经资金进出调整的净权益高点H−当前净权益E)/H，H>0。已平仓净利润扣除真实交易成本，不用单笔浮盈替代。

按以下优先级判定：

1. 已停机且未经人工恢复，保持停机；D≥10%进入停机：停止新增风险、取消待执行入场和加仓，处理存量风险、人工复核，不自动恢复。
2. D≥5%进入保守。首次进入时保存触发降档前的高点H_restore，不在回撤中向下移动恢复线。
3. 已在保守且E<H_restore，保持保守；E≥H_restore可在盘前先恢复正常，同次判定不直接跳积极。
4. 积极档的当前利润安全垫(E−阶段本金)/阶段本金≤5%，降正常；若同时触发回撤条件，执行更严的保守或停机。
5. 正常档且已平仓累计净利润≥阶段本金10%、当前E≥阶段本金110%、无回撤限制时，获得积极档资格。需盘前明确批准才生效，不自行升级。
6. 有完整历史且无上述条件，保持原档；无状态历史先核验，不把“默认正常”用来绕过回撤审查。

升档盘前生效。触发降档／停机后立即停止不合规新增；存量超出新限额时按预定减仓规则处理，不放宽止损。减仓顺序未配置时标人工处置，不虚构优先级。

不叠加旧+10%／-8%账户规则，或摘要中的25%停机、连续三亏减半、日亏5%、月亏6%等未经本版本采用的阈值。

## 5. 本轮、组合、相关性与当前权益风险

本轮指同一品种、同一方向、同一段逻辑的首仓、加仓和再次尝试。用轮次标识记录；换合约、改名、重开卡不重置。新一轮需新结构依据及盘外登记。

### 本轮成本账

令d=+1为多头，d=−1为空头，q为手数，M为乘数，P为入场价，S为止损价。

- 各批未实现计划亏损=max(0,d×(P−S))×M×q。
- L为本轮已经发生的亏损与费用之和；盈利不抵消L；费用只计一次。
- 本轮使用额=L+各批未实现计划亏损之和+尚未发生的退出费用及预估滑点。
- 本轮使用额≤冻结预算B。成交前把预计开仓费用纳入，成交后归入L，避免重复。
- 再次试错与新增批次只能使用剩余预算。本轮已实现盈利不自动补充额度。

### 组合计划风险池与相关单元

- 组合计划风险=sum(各持仓非负计划亏损+尚未发生费用与滑点)+待执行入场／加仓预留风险。
- 组合池上限按第3节，基数为当前净权益。所有可能同时成交的计划都预留预算；没有明确互斥机制不能重复占用同一额度。
- 同板块／共同驱动合并风险单元，合计计划风险≤当前净权益×账户单轮上限。
- 不以不同合约或不同品种名称拆散共同风险；不未经验证用多空相抵释放额度。
- 本轮累计已损L不重复加到“同时持仓风险池”，它已进入净权益并独立消耗本轮预算；组合池不是允许每天重新损失同一比例的额度。

### 当前权益账

当前价格C退到防守位的计划回撤=max(0,d×(C−S))×M×q+尚未发生的退出费用与滑点。跨全部持仓合计，不抵扣其他仓位可能盈利；新增风险评估还考虑待执行计划的最不利允许成交情形。

新增／加仓后，当前权益至全部防守位的计划回撤也须≤该账户档位组合风险池。持仓上涨使潜在回吐扩大时禁止新增，按既定跟踪规则管理，不为释放额度机械挤压止损。计划风险不保证跳空或停板的实际成交损失。

### 保证金与资金

风险金额、当前权益回吐、名义敞口、保证金占用分别核算。账户总保证金上限、单品种限额、最低可用资金及事件压力情景需由账户配置提供，本版不默认摘要中的20%／50%等参数。缺失时不出可执行手数。

## 6. 四种入场—止损配对

| 方法 | 做多 | 做空 |
|---|---|---|
| 单边切入 | 有序推进中按明确触发参与；指定前一根完成K最低点止损 | 镜像，前一根最高点止损 |
| 反K突破 | 突破指定反K组最高点；组最低点止损 | 跌破组最低点；组最高点止损 |
| 反K收线 | 指定反K完成且条件满足后参与；前一根反K最低点止损 | 镜像，前一根反K最高点止损 |
| 穿10均线 | 顺势穿越／重回MA10；均线下方平台最低点止损 | 镜像，均线上方平台最高点止损 |

依据“品种×周期×当前结构”选择唯一配对，记录流畅度、反K质量、位置及波动。历史证据和当前适配假设分开写，不固定全局主次。

必须指定K线时间、组／平台范围、触发价格、触价或收盘确认、下一可成交窗口、允许价格区间、有效期。未指定时不是可执行计划。

原总纲以完成日K为基础，其他周期的迁移需要显式确认适配及确认方式。单边“流畅”不等于完整触发；“最后一根反K”不得未来倒推；只有一根反K且找不到有效“前一根”时不得擅改成组极点。做多初始止损必须低于入场，做空必须高于入场，零距离拒绝。

以最小变动价位核对价格；价位非合法跳动单位时修正依据并重算，不偷偷四舍五入缩窄结构。缓冲点数不得自造。突破即入与完成突破K确认须事前选定；收盘确认不能假设成交在已过去的收盘价。

## 7. 仓位计算与止损纪律

每手风险=|计划入场价−有效止损价|×合约乘数+每手开平费用+滑点金额。

风险手数=floor(本轮剩余可用预算/每手风险)。最终手数取本轮、账户池、相关单元、当前权益回撤额度、保证金、流动性各项允许值的最小整数。入场区间按不利价格计算；不足1手不做。已有仓位的计算使用第5节，勿把盈利止损的距离绝对值算作本金亏损。

本轮金额先定，技术止损独立有效，再反推手数。不为增加手数压缩止损。入场即设、不可放宽、不可取消、不可协商。硬止损触发不等收盘。信号过期或超允许成交范围不追价。

## 8. 持有、退出与加仓

初始止损判断入场错误，跟随退出判断持有结构失效，两者均事前定义。

- 单边结构：按指定完成K高低点规则更新防守。
- 反K节奏：新反K完成并恢复推进后，按规则评估防守更新。
- 平台重启：初始守平台，新平台／选定结构完成后更新。
- 指定更新触发、更新价、生效时刻及退出确认方式；只收紧不放宽。硬止损与收盘结构退出不可混用。
- 时间退出须有该结构的依据、N根K定义及退出窗口。不自动添加2R保本、固定目标、ATR或RSI规则。
- 快速浮盈分批止盈仅按预先选择的条件、数量、余仓规则执行，不临场发明。

保守不加仓。正常／积极仅在盘前指定时允许：原仓浮盈、五层核心仍在、新信号有效、新增止损有效、旧止损不放宽、所有风险约束合格。每批手数严格递减，不固定5/3/2；整数不足则不加。浮亏不加仓、不摊平。注明各批止损、共同退出或分批退出顺序、最大批次。

五层升档不自动扩本轮预算。五层降四层停止加仓，按既定环境退出规则处理。少于四层取消未成交入场；存量须有明确的减仓／退出条件与时点。未规定时输出人工处置缺口，不自行宣称立刻清仓或继续持有。

## 9. 成交异常与结束

核对实际成交价量与止损接受状态；部分成交按实际数量保护。成交导致风险超额，按预定减仓办法处理，不扩大止损。止损拒绝／失效／触发未成交必须明确报警和人工处置，不能记为已平仓；无交易连接时仅给人工核对清单，不宣称已挂单或实时监控。

退出后核对残仓、撤销遗留订单的人工确认、成本和实际结果。超计划亏损分别归因于规则偏差、执行违规、滑点跳空或数据问题，不把任何超过2%的亏损一概判违规。

复盘四项：环境、方法、管理（含加仓贡献与回吐）、执行。按同类样本观察平均风险倍数、成本、止损频率及回撤，不把30笔当盈利证明。盘外提出改版，用户批准后执行。

## 10. 未配置项的行为

本版已确认默认阶段本金和测算基准为100万元，但不是已填好全部实时数据的真实账户。以下缺项会阻止具体计划获得“可执行”状态，但不阻止输出研究性条件卡：大盘／板块判向来源；实际净权益、高点和档位历史；保证金限额；精确单边／反K收线触发；持仓环境降级退出方式；减仓顺序；加仓批次与逐批止损；真实参数、价格或订单状态。

先完成能做的核对，一次只追问最影响行动的缺项。禁止为补齐表格而猜值。
