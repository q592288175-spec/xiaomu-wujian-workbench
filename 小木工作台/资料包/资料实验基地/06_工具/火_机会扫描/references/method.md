# 三模式方法口径 v2.2

判定顺序：流动性硬门 → 方向 → 最小周期结构 → 极值突破 → 模式归类。

## 一、流动性硬门（全局）

```text
流动性合格 =
成交量 > 20,000
且持仓量 > 20,000
```

- 数据取当前具体主力合约最新完成交易日的成交量与持仓量，二者与价格同源同K线。
- 等于 20,000 手不合格（严格大于）。
- 成交量或持仓量任意一项不合格，三个模式全部失去观察资格，报告标记为“流动性不合格”。
- 成交量或持仓量缺失、量仓日期与技术行情日期不一致，列为“数据不足”。
- 主力连续的成交量与持仓量不得替代当前具体主力合约的数据。

## 二、方向

```text
上升 = 当前MA10 > 上一MA10
下降 = 当前MA10 < 上一MA10
走平 = 当前MA10 = 上一MA10
```

MA10 为最近 10 根对应周期收盘价的简单算术平均。方向只比较相邻两个 MA10 值，不要求当前价格位于均线上方或下方。

## 三、结构

```text
周低点抬高 = 本周截至最新日K的最低点 > 上一完整周最低点
周高点降低 = 本周截至最新日K的最高点 < 上一完整周最高点
日多头结构 = 前1日最低点 > 前2日最低点，且最新日最低点 >= 前1日最低点
日空头结构 = 前1日最高点 < 前2日最高点，且最新日最高点 <= 前1日最高点
```

周结构相等不算抬高或降低。日结构中，前1日必须严格形成抬高或降低；最新日与前1日结构点相等视为“未破坏”。

## 四、极值突破

```text
月线突破窗口 = 最近3个月 对比 再向前5个月   （共8个月）
周线突破窗口 = 最近3个完成周 对比 再向前5个完成周 （共8个完成周）

月线新高 = 最近3月最高价 > 前5月最高价
月线新低 = 最近3月最低价 < 前5月最低价
周线新高 = 最近3周最高价 > 前5周最高价
周线新低 = 最近3周最低价 < 前5周最低价
```

价格相等不算创出新高或新低。周线突破只使用已完成自然周。

月线研究序列：主力连续提供长期历史月K；当前动态月K使用当前具体主力合约截至扫描日的 Open／High／Low／Close 覆盖校正，因此当月未走完也参与计算。

## 五、模式归类

```text
月周多头 = 流动性合格 且 月上升 且 动态周上升 且 本周低点高于上周低点 且 月线新高
月周空头 = 流动性合格 且 月下降 且 动态周下降 且 本周高点低于上周高点 且 月线新低

周日多头 = 流动性合格 且 动态周上升 且 日上升 且 日多头结构未破坏 且 周线新高
周日空头 = 流动性合格 且 动态周下降 且 日下降 且 日空头结构未破坏 且 周线新低

三周期多头 = 流动性合格 且 月上升 且 动态周上升 且 日上升 且 日多头结构未破坏 且 月线新高
三周期空头 = 流动性合格 且 月下降 且 动态周下降 且 日下降 且 日空头结构未破坏 且 月线新低
```

**v2.1 修正**：月周日共振只继承月线 8 个月突破，不叠加周线 8 周突破。因此在极少数情形下，一个品种可能满足月周日共振而不满足周日小周期（周线突破缺失）。这是刻意保留的口径，报告不做额外拦阻。

## 六、样本要求

```text
月MA10方向：至少11根月K
周MA10方向：至少11个周K，最后一根为截至最新日K的动态本周K
日MA10方向：至少11根日K；日结构至少3根日K
月线突破：至少8根月K
周线突破：至少8个完成周K
```

任一项不满足，或当前具体主力数据陈旧、映射缺失，列为“数据不足”，不做主观补判。

当日15:30后历史日K尚未落库时，可用同一具体主力合约的盘后收盘快照补齐当日开高低收、成交量与持仓量；21:00夜盘开始后不再使用该补丁。

## 七、板块

板块字段只承担报告分组，不参与任何布尔判定，不生成综合评分或强弱排名，报告保持配置顺序。

## 八、15:30盘后数据

- 历史日K取新浪具体合约；15:30后优先用交易所已发布日行情补齐目标交易日。
- 交易所数据尚未取得时，可使用新浪带合约代码、当日日期且时间不早于收盘的快照。国债需15:15及以后，其他合约需15:00及以后；夜盘快照不作为日盘收盘。
- 快照记录标为“待正式复核”，再次刷新时以正式日行情优先；收盘价与结算价分开，不用结算价代替收盘价。
- 行情未达到目标交易日不得成为候选；交易所明确零成交、零持仓的品种标记“当日无成交”，不生成价格为零的K线。
- 保留原始来源快照、具体合约缓存与历次扫描结果。免费接口不承诺15:30全量必达，页面逐品种显示数据日期、来源和缺口。
