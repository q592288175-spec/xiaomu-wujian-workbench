# 五简期货账户管理系统

2026-09-27｜整理版 v1.0｜当前流程，效果验证中

## 一、系统只解决五个问题

1. 火：哪里存在值得观察的机会？
2. 水：我看到的事实是什么，什么证据会推翻解释？
3. 金：这笔风险是否值得承担，错误在哪里结束，最多配置多少？
4. 土：计划有没有按真实成交执行，异常谁来处理？
5. 木：赚亏来自哪里，哪些规则需要保留、修改或删除？

底层保留“择境、严格止损、以损定量”。第一性原理是：账户只能承受有限损失；单次结果不确定；手续费与滑点是真实成本；策略是否有优势必须接受数据反证。纪律能保证规则一致，不能把无优势规则变成盈利系统。

本版仅覆盖国内期货，不纳入旧合作文本中的期权卖方策略。多个账户各自记账、授权、算风险，不用一个账户的盈利掩盖另一个账户的超限。

## 二、唯一规则权威

本手册规定工作流程。精确决策参数只在[规则与计算口径](../06_工具/金_决策复核/references/规则与计算口径.md)维护，以9月27日已确认的期货决策助手为准。它保留原文与原哈希。扫描参数只在[三模式方法口径](../06_工具/火_机会扫描/references/method.md)维护。

9月26日的纯月周三条件及3%/6%/10%旧风险池不再作为本基地的交易许可规则；9月27日扫描技能的双2万手和突破窗口只决定工具观察名单。三模式扫描不产生大盘、板块五层权限。历史合同的10%/18%/20%条款保留为责任证据，不覆盖当前内部风险控制，也不因本次整理自动改约。

旧文档标题里的“当前”“唯一”“最高”只代表当时版本。发生冲突时查本入口及规则原文，不能在盘中挑更宽松的一份。

## 三、火：识别机会

输入：截至指定时间的数据、品种全集、当前具体主力映射、所用扫描版本。输出：带时间戳的候选及未纳入原因。

使用多周期扫描v2.2。先要求同一具体主力盘后成交量、持仓量均严格超过2万手；再输出月周、周日、月周日三类名单。周结构使用动态本周K对比上周；日结构要求前1日相对前2日严格形成结构，最新日未破坏前1日结构点。均线方向、周结构与突破使用严格比较；日结构的最新日保护允许相等。工具方法文件是计算细节的唯一入口。

月线允许动态月K，但必须标“未完成”；周、日的完成状态按数据口径判断。长期主力连续不能直接用于具体合约的进场价或止损价。换月必须复核实际合约，保留当时映射；历史扫描不能用今天的主力映射假装当时可知。

火只输出：品种中文名、具体合约、候选方向、扫描模式、关键数值、数据截止、版本、异常、失效时间。没有合格对象就输出空名单，不为了凑名额降低门槛。自动列表外的候选须标记来源，不冒称通过扫描。

拒绝：行情陈旧或缺失、映射不明、窗口不足、时间错位。研究可以继续补证据，但不能用推测填上数值。

## 四、水：分析机会

输入：火的候选、具体合约图形、按品种加载的研究框架。输出：一段结论、一条主要反证和待核验项目，写入同一张交易卡。

按“先价、再量、后仓”核实结构。价格高低点和十期均线是观察；“新多主导”“空头回补”“供应短缺驱动”是解释，不能混写。总持仓增加同时包含多空两方，不能单凭增仓认定资金方向。成交量也不直接等于净流入。

研究只回答四问：什么在改变；证据在哪；价格是否已经反映；何种事实会推翻判断。每个事实记录统计期、公开时间、获取时间、单位和原始出处；转载不算独立证据。库存、产量、需求、利率、汇率、运价等依品种选取，不给所有期货套同一套供需故事。

至少列一个竞争解释，例如价格上行也可能来自风险偏好或平仓，而非现货缺口。缺数据就保留“未知”。没有可校准的频率或模型，不写80%之类精确概率，不把加权评分称为贝叶斯后验。

水可以提出等待、撤回假说和事件风险提示；不能修改五层事实、放宽金的风险上限或把基本面信心当成加仓许可。量价仓、12节点和宏大叙事都不增加新的盘中硬门。

## 五、金：做决策

输入：五层环境证据、账户状态、主周期、唯一入场止损配对、真实合约参数。输出状态只有“待证据、观察、待触发、已批准、拒绝”，附明确原因。

大盘、板块、品种月K、周K、日K逐层登记标的、判向方法、时间和方向。四层同向且第五层中性才允许按已确认规则评估保守测试；第五层反向或未知都不能混成中性。五层同向只是允许继续评估，仍然需要账户、触发和风险全部合格。

账户档位、环境上限和主周期上限取最小值。用首次批准前核验的权益冻结本轮预算；同一品种同一方向同一逻辑的首仓、加仓与连续试错合用一个轮次编号。重开卡、换合约、出现浮盈都不能重置预算。

从四种配对中选一种：单边切入与前完成K极点、反K组突破与组极点、反K收线与前一有效反K极点、穿十期均线与指定平台极点。选择依据写入计划；不把反K突破指定为未经验证的全局最优。精确K线时间、组范围、触发方式、允许成交区间、有效期和下一可成交时点缺一不可。反K只有一根却需要“前一根”时，不能临时换定义。

计算顺序：核实账户权限 → 确定风险预算 → 独立确定技术止损 → 按最不利允许入场价、乘数、费用和滑点算每手风险 → 对本轮剩余额度、组合池、相关单元、当前权益回吐、保证金和流动性分别求可用手数 → 取最小非负整数。不足一手就不做。

本金风险和浮盈回吐分账。盈利仓止损高于入场价，不代表其从现价退到止损没有回撤。所有可能同时成交的挂单都预留风险；未经验证的对冲不能释放额度。各式计算及账户升降档严格使用规则原文，禁止重复维护第二张参数表。

批准前必须同时冻结持有与退出：初始硬止损、跟踪止损如何更新、结构退出、环境降级的存量处理、换月或临近交割的退出、事件处理及异常联系人。没有配置的动作不能靠交易员临场发挥。

## 六、土：执行与管理

执行者只接收已批准且仍有效的卡。下单前核对账户别名、具体合约、买卖、开平、价量、当日费用、保证金及剩余风险；研究截图不是委托依据。

提交委托、交易系统接受、部分成交、全部成交、撤单成功、止损触发、实际平仓是不同状态。必须根据回报记录，不能把点击按钮当成交。部分成交只保护实际仓位；剩余挂单继续占风险额度，撤单待确认仍视为可能成交。

入场后核对止损是否被接受，以及断网、停机、夜盘时是否仍有效。硬止损触发不等收盘，不扩大止损、不撤销保护。条件单触发但未成交进入异常处理，不记为“已退出”。涉及交易所停板和流动性不足时实际亏损可能越过预算；中期协的[风险教育说明](https://edu.cfachina.org/zsyd/ywzn/ibywzn/201208/t20120822_20403.html)明确讨论了停板无法及时成交及技术故障风险。

已有规则允许的加仓也要重新走金：原仓浮盈、五层核心仍成立、新信号与止损明确、每批手数严格递减、所有预算合格。保守不加仓，浮亏不加仓，不为凑手数压缩止损。

异常处理顺序：停止新增 → 确认真实持仓与尚未撤掉的委托 → 保留或恢复有效保护 → 通知风控和账户负责人 → 依预定方案减风险 → 记录实际回报。无法确认仓位时不重复下相同指令。系统没有连接或监控能力时，仅人工逐项核验，不声称自动完成。

退出须做“三清”：持仓核清、普通委托核清、条件单核清。持有过夜时“三清”指账实一致和保护有效，不要求趋势仓每天清仓。换月旧仓与新仓同时存在期间合算风险、费用与成交，不把换月当成新预算。

## 七、木：检查成果并迭代不足

盘后将计划与结算、成交、费用逐项对账。每笔同时给执行结论和结果结论：合规盈利、合规亏损、违规盈利、违规亏损。盈利不能洗掉违规；合规亏损也不能自动归咎执行者。

归因依次区分数据错误、规则缺定义、执行偏差、滑点/跳空、策略正常波动和待验证的策略退化。同一轮全部尝试合并统计，不能删除试错只展示最后盈利一笔。成本、出入金、浮盈和平仓利润分开记录。

周末检验净期望、回撤、成本、规则内执行率、风险超额、漏做与误做、加仓贡献与回吐。采用[验证协议](../03_迭代/2026-09-27_验证与迭代协议_当前_v1.0.md)，先提出能被否定的假设，再做时间顺序样本外对照。30笔只能帮助发现流程问题，不能证明长期盈利。

错误数据和算术缺陷立即修正并留痕；交易逻辑变更在盘外冻结新版本，不回写已发生交易。新版本先并行记录模拟结果，批准后切换；禁止边持仓边修改规则解释亏损。

## 八、团队约束与上线条件

研究员负责火水；账户负责人批准金；交易员负责土；风控负责预算、否决和异常；复核者负责木。同一人可兼任，但不能把自审冒称独立复核。新增与加仓必须有明确批准记录，风险超限任何人可提出停止新增。

真实账户启用需要账户配置完整、具体触发可重复判定、软件操作与应急演练通过，以及真实历史/模拟证据和人工批准。默认阶段本金及仓位、风险预算、手数示例已按用户确认统一为100万元；实时净权益、高点、档位、保证金约束等仍未填入，因此本系统尚不等于已经具备下单许可的账户。

旧合作协议的签署、责任基准和主体状态未知，原件保留。对外资管资格与合同责任须按实际业务核定；本次不作法律有效性判断。参考[2023年资管业务管理办法](https://www.cfachina.org/governmentrules/departmentregulations/202301/t20230116_35180.html)，其适用主体及业务要求不能由内部交易手册代替。
