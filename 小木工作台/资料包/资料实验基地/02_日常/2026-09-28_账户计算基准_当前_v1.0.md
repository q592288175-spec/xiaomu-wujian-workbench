# 五简期货账户计算基准

日期：2026-09-28  
状态：当前

## 已确认口径

- 默认阶段本金与所有仓位、风险预算、手数示例的计算基准：**1,000,000元（100万元）**。
- 以后未特别说明账户规模时，一律按100万元计算，不再按10万元举例。
- 风险比例仍按当前金决策规则执行，本文件只确定金额基数，不改变风险比例、环境权限、周期上限或止损规则。

## 100万元对应风险金额

| 项目 | 比例 | 金额 |
|---|---:|---:|
| 保守档单轮上限 | 0.5% | 5,000元 |
| 正常档单轮上限 | 1% | 10,000元 |
| 积极档单轮上限 | 2% | 20,000元 |
| 保守档组合风险池 | 2.5% | 25,000元 |
| 正常档组合风险池 | 5% | 50,000元 |
| 积极档组合风险池 | 6% | 60,000元 |
| 日K主周期上限 | 1% | 10,000元 |
| 小周期上限 | 0.5% | 5,000元 |

实际单轮风险金额取“账户档位、五层环境、主周期”三项上限的最小值。例如积极档做日K交易，仍受日K 1%上限约束，最多按10,000元预算，不按20,000元预算。

## 实盘核验边界

100万元是用户确认的默认阶段本金和统一测算基准，不自动证明某个真实账户当日净权益恰好为100万元。每一轮真实交易批准前，仍须核实当时净权益 `E0`；如实际净权益与100万元不同，明确列出差额，并以经核实的 `E0` 冻结本轮预算。历史高点、当前档位、已平仓净利润、保证金约束和停机状态仍须单独核验。
