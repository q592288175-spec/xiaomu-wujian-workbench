# 长期位置与当前状态 v2.5

## 目的与兼容边界

月周大周期和周日小周期沿用原MA10、结构、3/8突破和双2万手规则；月周日共振改用月、周、日MA10同向与3/12月线突破，删除日K结构硬条件。关注层不覆写原始资格：JSON的 `technical_modes`、`modes` 及原计数按各模式口径保留，新增 `attention`、`attention_counts` 与首页清单。

周方向和周结构使用动态本周，周日小周期的日结构使用三日保护链；月周日共振不要求周线8周突破，也不要求日K结构。

首页依次显示重点关注、蓄力观察、暂缓关注、数据待核，并按既有板块分组。不排序预测收益，不凑数量。以下数值是可复核的初始工程定义，不是用户逐项确认的最优参数，也不是已验证的胜率或二八定律。调整只影响关注层。

## 长期位置

长期位置使用主力连续、截至扫描日的月K；当前动态月已经由具体主力校正。月MA10方向则使用当前具体主力月收盘序列。8、12、18个月分别计算，不用不足的样本冒充完整窗口。

`位置 = (当前具体主力收盘价 - 窗口最低价) / (窗口最高价 - 窗口最低价)`。

- 默认主观察窗12个月，位置 >= 75% 为高位，<= 25% 为低位；两端之间为区间中部。
- 多头关注层要求高位，空头要求低位。这里的75%不是价格离新高25%，而是整个高低区间的位置。
- 8、18个月位置及最近3个月是否创12、18个月新高/新低作为对照。**不要求12、18个月突破同时成立**；18个月不足不否决12个月判断，但标记不足。
- 12个月不足、月份不连续、极值缺失、区间宽度为零，关注层列数据待核，原三模式结果保留。
- 18个月与12个月位置冲突单独提示，不假装两者共振，也不静默变成额外门槛。
- 长期序列仍是未复权主力连续研究口径；新高/新低及历史位置可能受换月价差影响，报告明确提示人工核对。不能称为具体合约18个月实盘历史。

## 当前突破边界

各模式的滚动窗口只回答“近期极值是否超过前段”。当前状态另查最近3根对应周期K内的独立突破事件：月周大周期和周日小周期使用此前5根参考K，共振使用此前12个月参考K；该根最高价严格高于参考区间最高价（空头镜像）。取最近一次事件，并记录它的事件周期、首次触及日、参考区间及固定边界。

这是关注层的边界核验，不改各模式的原始突破窗口。若旧极值滚出窗口使原条件成立、但近期没有可核验事件，列数据待核，不伪造突破日期。以后只有发生新事件才能更换事件边界；同一事件不会因为扫描日后移而重新计算其固定参考区间。

- 月周、共振使用月事件；周日使用完成周事件，不把动态周塞进原8周窗口。
- 月事件首次触及日按同源月线研究日序列核对；周事件按具体主力日序列核对。
- 当前收盘仍在突破方向的边界外：突破保持。
- 收盘恰好位于边界，或首次收回边界内：回踩待确认，不列重点，不直接声称趋势终结。
- 事件发生后连续两个完成交易日收在边界反面：突破失守，移出重点/蓄力清单，但保留原资格与降级证据。
- 只看盘中最高/最低价触及而收盘没有站稳，不算保持。长影线本身不等于失效。

## 当前形态

月周模式以周K观察，另外两模式以日K观察。周形态的参考区间只取当前周之前的完成周；动态本周仅作为当前判定，明确标注待周收盘，不能把周一的小振幅当成已完成的周蓄力。

1. 参考当前K之前10根；取其中最后4根的最高/最低价为整理区间。
2. `整理宽度比 = 最后4根区间宽度 / 此前10根整体区间宽度`，默认 <= 0.35 视为紧凑整理。这里只描述收缩，不证明能量积累或未来爆发。
3. 紧凑整理后，当前收盘严格突破整理上沿/下沿，且当前收盘相对前收继续顺向推进，标记“蓄力后上破/下破”。影线突破、收盘相等均不成立。
4. 当前收盘仍在紧凑区间内，且最新K未穿破区间边界，标记“高位整理/低位整理”，只列蓄力观察；若穿破反向边界，列回撤待确认；若顺向影线突破但收盘收回，列上破/下破未站稳，不伪装为健康蓄力。
5. 无紧凑突破时，最近10个收盘变化的同向净位移 / 绝对变化之和 >= 0.60，且其中至少60%的收盘变化顺向、最近两个变化不是连续反向、当前收盘仍顺向，标记“持续清晰推进”。其余为“推进放缓/反复”，不是趋势已终结。
6. 对月周大周期和周日小周期，原最小周期结构未通过不进入重点；若仅结构未通过、方向和原突破合格，并且位置、边界、紧凑整理均成立，可保留“蓄力观察（原结构未成立）”。月周日共振没有日K结构硬条件，按其3/12月线突破和三周期方向判断。

## 关注分层

共同前提是最新同日数据、双2万手、相应模式方向及原突破。另要求月MA10与关注方向一致，避免周日反月线的候选进入大趋势重点池；原周日资格不被改写。

- **重点关注**：原模式全部通过；12个月位置符合；突破保持；蓄力后上破/下破，或持续清晰推进。
- **蓄力观察**：相同大方向、位置和突破保持，当前处于紧凑整理。显示原结构是否已成立，等待价格表态。
- **暂缓关注**：原方向与突破有基础，但位置不合适、月线相反、回踩/失守、原结构未成立且并非健康整理，或推进不清晰。逐条显示原因。
- **数据待核**：新增观察所需资料不足或无法确认事件边界；原始名单仍保留。
- **未纳入**：流动性、原方向或原突破不满足，不由关注层补救。

同一品种不同模式可能有不同状态，不把周线清晰误写成日线同样清晰。首页只展示本次选择的模式。量仓只继续执行双2万手，不新增资金流向解释；供需、板块强弱、60分钟、止损、仓位仍在技能之外。

## 验证与使用

验收包含原规则回归、多空镜像、边界相等、旧突破失守、底部反弹/顶部回落、紧凑整理及收盘突破、数据不足、未来数据截断、报告/JSON兼容。合成数据只验证算法，不算真实行情或绩效。

随后需要用固定历史截点比较原名单与新增关注层，检验误纳、漏选、反复折返和持续推进；未经样本外验证，不宣称能过滤95%无效行情、准确定位高潮或保证20%时间走80%空间。
