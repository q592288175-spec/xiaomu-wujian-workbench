# 五简期货多周期筛选 v2.5.1

面向国内期货盘后研究的技能包。一次读取行情，先执行流动性双2万手硬门，再分别输出三种互不干扰的观察名单。

v2.5保留三模式与长期位置关注层，并把月MA10方向改为当前具体主力合约月收盘序列，以对齐文华主力图；月线极值突破继续使用主力连续长期序列。月周日共振仍是月、周、日MA10同向，最近3个月对比此前12个月创出对应新高或新低。整理只是观察状态，不预判必然突破。

## 每天先看什么

先打开 `日期_关注清单.md`，按板块查看：

- 重点关注：原模式合格，12个月长期位置合适，顺月线方向，突破保持，当前正在清晰推进或整理后上/下破。
- 蓄力观察：长期环境仍在，当前紧凑整理，等价格表态；原结构未成立的项目明确注明，不伪装为正式候选。
- 暂缓关注：长期位置不合适、逆月线、突破回踩/失守、结构未恢复或反复折返，逐项解释。
- 数据待核：历史不足、无法核验突破事件或新增计算失败；不抹掉原三模式结果。

默认以12个月高低区间的上/下25%区分高位/低位，同时显示8、18个月位置；不要求创12、18个月新高/新低。数值为待验证的初始操作定义，配置在 `config/products.json` 的 `attention`。完整公式、边界与局限见 [关注层规则](references/attention.md)。

## 三种模式

1. **月周大周期**：流动性合格；月、动态周MA10上升（空头镜像下降）；本周截至最新日K的低点高于上周低点（空头为高点降低）；最近3月创15个月新高（空头为新低）。
2. **周日小周期**：流动性合格；动态周、日MA10上升（空头镜像）；前1日低点高于前2日且最新日未破前1日低点（空头镜像）；最近3个完成周创8周新高（空头为新低）。
3. **月周日共振**：流动性合格；月、动态周、日MA10上升（空头镜像）；最近3个月最高价严格高于此前12个月最高价（空头为最低价严格低于此前12个月最低价）。不叠加周线8周突破，也不要求日K高低点结构。

## 流动性硬门

使用当前具体主力合约最新完成交易日的成交量与持仓量，两者都必须严格大于 20,000 手。等于 20,000 手不合格。不合格的品种在三个模式中一律失去观察资格，并在报告中单列原因。

## 品种与数据

- 配置包含 87 个国内期货品种，覆盖商品、股指和国债期货。
- 月线使用新浪主力连续历史，并用当前具体主力当月数据校正动态月K。
- 动态周线、日线、结构、周线突破、成交量与持仓量均使用当前具体主力合约；周线突破窗口仍只使用完成周K；共振月线窗口使用主力连续月K并要求15个月样本。
- 当前具体主力映射通过 AkShare 读取；陈旧、缺失或样本不足的品种单列，不主观补判。

python -m pip install -r requirements.txt

## 使用

默认同时运行三种模式：

```powershell
python scripts/scan.py
```

只运行一种模式：

```powershell
python scripts/scan.py --mode month-week
python scripts/scan.py --mode week-day
python scripts/scan.py --mode month-week-day
```

指定复盘截点或品种：

```powershell
python scripts/scan.py --as-of 2026-09-25
python scripts/scan.py --codes CU,AG,AD,AO
```

本机请在 `D:\五简个人资料` 下的明确工作目录运行。结果保存到当前工作目录的 `.wujian-futures-multi-cycle-scan`，同时生成完整Markdown、精简关注清单及JSON数据。

JSON原有 `modes`、`technical_modes`、`counts` 保持原资格含义；新功能位于 `attention`、`long_term_position`、`attention_counts`、`attention_parameters`。旧下游界面不会自动展示新字段；未经适配不能把旧页面叫作新版关注首页。

## 边界

本项目只筛选观察环境，不读取60分钟图，不提供入场、止损、仓位或自动下单功能。月线在月末收盘前会动态变化，具体合约与换月情况仍需人工复核。

## 维护要点

- `config/products.json` 的 `main_contract_overrides` 为人工主力补充项，换月后可能失效，需周期更新。
- 流动性门槛与突破窗口均可在 `config/products.json` 中调整，调整后应同步更新 `references/method.md` 与测试。
- 新关注层不额外访问网络，复用同一批月/周/日数据。合成测试通过只证明程序行为；长期位置受主力连续换月影响，筛选效果还需历史与样本外对照。
