# 五简期货多周期筛选｜一包三模式 v2.5.1

本技能只负责筛选值得打开60分钟图继续观察的品种，不判断60分钟切入，不制定止损、仓位或订单手数。

> 2026-10-21本人确认：本补丁只将月周大周期月线突破统一为最近3个月对比此前12个月。周日、共振及其他条件保持原值；小木继续按既有适配执行双1万手等现行规则，不把本包基础双2万手直接当成小木结果。

> v2.5：在 v2.4 基础上，将月MA10方向改为按当前具体主力合约自身月收盘序列计算，以对齐文华主力合约图；月线极值突破仍使用主力连续长期序列，并用当前主力校正当月。先读 [方法口径](references/method.md) 和 [关注层规则](references/attention.md)，不得只读摘要后自行重新解释公式。

## 每日优先工作流

1. 在D盘工作目录运行扫描脚本，核对目标交易日、当前具体主力、数据覆盖及双2万手。
2. 先交付 `日期_关注清单.md`：重点关注 → 蓄力观察 → 暂缓关注 → 数据待核，按板块分组，品种写中文全称。
3. 三种模式资格按各自规则保留在完整报告和JSON的 `modes`，新层在 `attention`。不得用新层覆写原资格或把蓄力等待项计入正式模式合格数。
4. 长期位置默认12个月区间的上/下四分之一；8、18个月对照，不要求12、18个月突破。窗口不足不缩短冒充；月线连续序列的换月影响须提示复核。
5. 重点只列原资格通过、顺月线背景、位置合适、突破仍保持且正在清晰推进或整理后上/下破的品种。整理中的等待项不预判突破，原结构未成立须明确标注。
6. 最新一根K不漂亮不等于趋势结束。区分盘中影线、收盘回踩与事件之后连续两日收盘失守；每项保留边界、日期和降级原因。月周事件边界按此前12个月固定；周日事件边界仍按此前5个完成周固定，共振事件边界按此前12个月固定，不随窗口滚动伪造历史新突破。
7. 没有合格重点就写“暂无”。默认参数是待验证的操作定义，不宣称筛掉95%无效行情、预测高潮或保证20%时间走80%空间。基本面、资金解释和60分钟切入仍由后续研究与用户判断。

实现沿用已有v2.2：动态本周参与周MA10和周结构；日结构为三根保护链；周线8周突破仍只用完成周。不要回退到旧安装副本的v2.1算法。

## 一、全局流动性硬门

所有模式统一执行以下条件：

1. 使用当前具体主力合约最新完成交易日的数据。
2. 当日成交量必须严格大于20,000手。
3. 当日收盘持仓量必须严格大于20,000手。
4. 成交量或持仓量任意一项小于或等于20,000手，直接过滤。
5. 成交量、持仓量缺失，或者量仓日期与技术行情日期不一致，列为“数据不足”，不得进入观察名单。
6. 主力连续成交量和持仓量不得替代当前具体主力合约数据。

严格公式：

流动性合格 =
成交量 > 20,000
且持仓量 > 20,000

等于20,000手也不合格。

## 二、MA10方向定义

MA10使用相应周期最近10根K线收盘价的简单算术平均。

上升 = 当前MA10 > 上一根MA10

下降 = 当前MA10 < 上一根MA10
走平 = 当前MA10 = 上一根MA10

MA10走平不算上升，也不算下降。

筛选不要求价格必须位于MA10上方或下方。

## 三、高低点结构定义

周低点抬高 =
本周截至最新日K的最低点 > 上一完整周最低点

周高点降低 =
本周截至最新日K的最高点 < 上一完整周最高点

日多头结构 =
前1日最低点 > 前2日最低点
且最新日最低点 >= 前1日最低点

日空头结构 =
前1日最高点 < 前2日最高点
且最新日最高点 <= 前1日最高点

周结构相等不算抬高或降低。日结构中，前1日必须严格形成结构；最新日与前1日结构点相等视为未破坏。

## 四、月线突破定义

月周大周期使用最近15个月：

- 最近3个月：当前动态月K＋前两个自然月。
- 此前12个月：再向前的十二个自然月。
- 当前月没有结束时，使用截至扫描日已经形成的月K高低点。

多头月线突破：

最近3个月最高价
严格高于
此前12个月最高价。

公式：

最近3月最高价 > 前12月最高价

空头月线突破：

最近3个月最低价
严格低于
此前12个月最低价。

公式：

最近3月最低价 < 前12月最低价

价格相等不算创出新高或新低。

月线极值突破使用主力连续提供长期历史月K，当前动态月K使用当前具体主力合约截至扫描日的数据进行校正。月MA10方向单独使用当前具体主力合约的月收盘序列，避免把换月后的连续序列当作文华主力图MA10。

月周日共振使用独立的15个月窗口：最近3个月与此前12个月比较；当前动态月包含在最近3个月内。

共振多头月线突破：最近3个月最高价严格高于此前12个月最高价。

共振空头月线突破：最近3个月最低价严格低于此前12个月最低价。

共振窗口不足15根月K时，月周日共振列为数据不足；不缩短窗口代替。

## 五、周线8周突破定义

周线窗口只使用最近8个已经完成的自然周，不使用本周尚未完成的周K。

- 最近3周：最近三个完成自然周。
- 前5周：再向前的五个完成自然周。

多头周线突破：

最近3周最高价
严格高于
前5周最高价。

公式：

最近3周最高价 > 前5周最高价

空头周线突破：

最近3周最低价
严格低于
前5周最低价。

公式：

最近3周最低价 < 前5周最低价

价格相等不算创出新高或新低。

周线突破统一使用当前具体主力合约。

## 六、模式一：月周大周期

### 多头观察

以下条件必须全部成立：

1. 流动性硬门合格；
2. 月MA10上升；
3. 周MA10上升；
4. 本周截至最新日K的最低点严格高于上一完整周最低点；
5. 最近3个月最高价严格高于此前12个月最高价。

公式：

月周多头 =
成交量 > 20,000
且持仓量 > 20,000
且月MA10上升
且周MA10上升
且动态本周低点抬高
且最近3月创15个月新高

### 空头观察

以下条件必须全部成立：

1. 流动性硬门合格；
2. 月MA10下降；
3. 周MA10下降；
4. 本周截至最新日K的最高点严格低于上一完整周最高点；
5. 最近3个月最低价严格低于此前12个月最低价。

公式：

月周空头 =
成交量 > 20,000
且持仓量 > 20,000
且月MA10下降
且周MA10下降
且动态本周高点降低
且最近3月创15个月新低

4. 前1日最高点低于前2日，且最新日最高点未突破前1日；
5. 最近3个完成周最低价严格低于前5个完成周最低价。

公式：

周日空头 =
成交量 > 20,000

且周MA10下降

## 八、模式三：月周日共振

月周日共振使用独立的月线突破窗口：最近3个月对比此前12个月。它不使用周线8周突破，也不使用日K低点抬高、高点降低或三日保护链。

### 多头观察

## 九、数据周期口径

1. 月K采用截至扫描日的动态月K，当前月尚未结束也参与月MA10和月线突破计算。
2. 周MA10与周K结构使用截至最新日K的动态本周K；本周直接与上一完整周比较。
3. 周线8周突破仍只使用已经完成的自然周，不使用动态本周K。
4. 日K结构只用于周日小周期；月周日共振不读取日K高低点结构。
5. 月线长期历史使用主力连续研究序列，并用当前具体主力合约校正当前动态月K。
6. 周线、日线、结构、周线突破、成交量和持仓量均使用当前具体主力合约。
7. 当前具体主力数据陈旧、映射缺失或者样本不足时，列为“数据不足”，不得主观补判。
8. 月周大周期月线突破至少需要15个月月K；周线突破至少需要8个完成周K；月周日共振的独立月线突破至少需要15个月月K；MA10方向至少需要11根对应周期K线；周日小周期日K结构至少需要3根日K。

## 十、板块与排序

1. 板块只用于分组展示。
2. 板块强弱不能增加或否决品种资格。
3. 不使用综合评分或综合斜率排名。
4. 不强行凑多头或空头数量。
5. 报告保持配置中的品种顺序。

## 十一、报告必须输出

每次扫描必须提供：

1. 扫描截点和最新技术行情日期；
2. 成交量、持仓量数据日期；
3. 87个品种的数据覆盖情况；
4. 三种模式过滤前后的多空数量；
5. 每个入选品种的中文名称、代码、当前具体主力合约；
6. 月、周、日MA10方向；
7. 周K或日K结构是否成立；
8. 最近3月极值与前12月极值；
9. 最近3周极值与前5周极值；
10. 最新完成日成交量和持仓量；
11. 因成交量或持仓量不超过2万手被过滤的品种及原因；
12. 因数据陈旧、缺失或日期不一致而被过滤的品种；
13. 按板块分组的最终多头和空头名单；
14. Markdown报告和JSON数据文件的保存路径。
15. 单独的每日关注清单、关注分层数量，以及原资格与新增关注状态的区别。
16. 8/12/18个月相对位置；JSON同时保留窗口极值、窗口日期和12/18个月突破旁证。
17. 当前突破事件固定边界、首次触及日、参考期间、收盘保持/回踩/失守，以及整理区间、推进效率、降级原因。
18. 临时收盘快照、动态周判断、长期连续序列及历史不足的复核提示。

## 十二、禁止增加的条件

除非用户以后明确修改，不得加入：

- 价格必须站上或跌破MA10；
- 成交量、持仓量的涨跌趋势解释；
- 量价仓共振或变异评分；
- 流动性排名；
- 基本面、供需或消息面；
- 板块强弱门槛；
- ATR距离；
- 综合斜率排名；
- 自动选择固定数量的多头或空头；
- 60分钟入场判断；
- 止损、仓位、订单手数或自动下单。

## 十三、使用边界

筛选结果只代表品种取得相应模式的观察资格。

入选后由用户自行打开60分钟图寻找切入节奏。未读取60分钟数据时，不得声称已经确认入场机会。

# 执行说明（v2.5 实现）

从D盘明确分类的工作目录运行，完整报告、关注清单与JSON写入该目录下的 `.wujian-futures-multi-cycle-scan`。本机唯一源码在D盘；安装入口为指向它的目录联接。其他AI按自己的可用Python解释器执行，不硬依赖本机路径：

```powershell
Set-Location 'D:\五简个人资料\文档\ChatGPT\交易研究'
python 'D:\五简个人资料\Codex\skills\wujian-futures-multi-cycle-scan\scripts\scan.py'
```

常用参数：

```powershell
# 指定复盘截点
# ... scan.py --as-of 2026-09-25

# 只核对部分品种
# ... scan.py --codes CU,AG,AD,AO

# 只输出一种模式（all / month-week / week-day / month-week-day）
# ... scan.py --mode month-week-day
```

字段与公式细节见 [方法口径](references/method.md)，品种与板块配置见 `config/products.json`，版本变更见 `CHANGELOG.md`。
