# 小木 · 五简交易系统

最新源码快照：2026-10-28。包含市场全景、全息版、火水金土木工作流，以及周日与日K观察池自动同步修复。

## 启动

1. 保持目录结构，进入 `小木工作台/wujian-jarvis`。安装 Node.js 22 以上版本与 Python 3.13。
2. 运行 `npm ci`。Windows 下执行 `py -3.13 -m venv .venv-akshare`，再执行 `.venv-akshare\Scripts\python.exe -m pip install -r requirements.akshare.txt`。
3. 如需研究模型、语音或消息推送，复制 `.env.example` 为 `.env`，在本机配置自己的服务。
4. 运行 `npm start`，打开 http://127.0.0.1:4318/market-panorama.html 。首次行情需在程序中刷新。
5. Windows 桌面构建：在项目目录执行 `npm run desktop:build`。

- `小木工作台/wujian-jarvis`：程序源码、界面、图形资产、依赖锁文件、测试与技术说明。
